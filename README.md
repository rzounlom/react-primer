# React Primer - Frontend Development Learning Path

A comprehensive collection of JavaScript and TypeScript learning materials, modern build tools, and practical projects designed to prepare you for React development.

## 🎯 Learning Objectives

This repository is structured to help you master:

- **Modern JavaScript Features** (ES6+)
- **TypeScript Fundamentals**
- **Build Tools & Development Environment**
- **Practical Application Development**
- **React-Ready Skills**

## 📚 Learning Modules

### 1. **Destructuring** (`destructuring/`)

Learn how to extract values from arrays and objects using destructuring syntax.

**Topics Covered:**

- Array destructuring
- Object destructuring
- Nested destructuring
- Default values
- Rest parameters with destructuring

**Files:**

- `arrays.js` - Array destructuring examples
- `objects.js` - Object destructuring examples
- `README.md` - Detailed explanations and exercises

### 2. **Spread Operator** (`spread/`)

Master the spread operator for combining arrays, objects, and function arguments.

**Topics Covered:**

- Array spreading
- Object spreading
- Function argument spreading
- Copying arrays and objects
- Merging data structures

**Files:**

- `arrays.js` - Array spread examples
- `objects.js` - Object spread examples
- `README.md` - Comprehensive guide with exercises

### 3. **Rest Parameters** (`rest/`)

Learn how to collect multiple function arguments into arrays and objects.

**Topics Covered:**

- Rest parameters in functions
- Array rest syntax
- Object rest syntax
- Combining with destructuring

**Files:**

- `array.js` - Array rest examples
- `object.js` - Object rest examples
- `README.md` - Detailed explanations and use cases

### 4. **TypeScript Fundamentals** (`typescript/`)

#### **TypeScript Setup** (`typescript/ts-setup/`)

Complete guide to setting up TypeScript with Node.js.

**Topics Covered:**

- TypeScript installation and configuration
- `tsconfig.json` setup
- Compilation process
- Development workflow
- Nodemon integration

**Files:**

- `complete/` - Fully configured TypeScript project
- `README.md` - Step-by-step setup guide

#### **TypeScript Basics** (`typescript/ts-basics/`)

Core TypeScript concepts and syntax.

**Topics Covered:**

- Basic types (string, number, boolean, etc.)
- Interfaces and type definitions
- Functions and type annotations
- Arrays and objects
- Type inference

**Files:**

- `src/index.ts` - TypeScript examples
- `package.json` - Project configuration
- `tsconfig.json` - TypeScript configuration

### 5. **Vite Overview** (`vite-overview/`)

Modern build tool projects demonstrating different development setups.

#### **Basic Projects**

- `vite-project/` - Vanilla JavaScript with Vite
- `vite-project-ts/` - TypeScript with Vite

#### **Todo Applications**

- `jquery-todos-ts/` - Full CRUD app with TypeScript + jQuery
- `jquery-todos-js/` - Full CRUD app with Vanilla JS + jQuery

**Features:**

- Hot Module Replacement (HMR)
- JSON Server backend
- Bootstrap UI components
- CRUD operations
- Async/await patterns

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v16 or higher)
- **npm** (Node Package Manager)
- **Git** (for version control)

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd react-primer

# Install dependencies for specific modules
cd <module-name>
npm install
```

## 📖 Learning Path

### **Phase 1: Modern JavaScript**

1. Start with **Destructuring** - Learn to extract data efficiently
2. Move to **Spread Operator** - Master data combination techniques
3. Complete **Rest Parameters** - Understand function argument handling

### **Phase 2: TypeScript Foundation**

1. Follow **TypeScript Setup** guide
2. Practice with **TypeScript Basics**
3. Build confidence with type-safe development

### **Phase 3: Build Tools & Projects**

1. Explore **Vite Overview** projects
2. Compare vanilla JS vs TypeScript implementations
3. Build the todo application from scratch

## 🛠️ Development Commands

### For TypeScript Projects

```bash
npm run dev      # Start development server
npm run build    # Compile TypeScript
npm run start    # Start with nodemon (if configured)
```

### For Vite Projects

```bash
npm run dev      # Start Vite dev server
npm run build    # Build for production
npm run preview  # Preview production build
npm run start    # Start JSON server (todo projects)
```
